# GENESIS panel background placeholders

These eight files provide the default faded artwork for the major Cockpit panels.
Their stable `panel-NN-*` names make the assignments easy to understand and replace.

Users can override any bundled default without editing code: double-click its artwork
in Cockpit Home, choose a replacement, then use **FRAME** to adjust crop and position.
The saved user choice takes priority over the bundled placeholder.

The larger top Cockpit banner currently reuses panel 01 as its default. Use
**SET BANNER** to give it separate artwork at any time.
